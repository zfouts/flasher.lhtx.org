MeshCore radio setup

Flash MeshCore onto your radio, then give it the settings Liberty Hill Mesh runs on. Every file, hash and setting is shown before anything is written.

This browser can't reach a radio. Writing to a radio needs Web Serial or Web Bluetooth, and this browser does not appear to offer either.

Chrome, Edge or Opera on a desktop or laptop can do it. On an iPhone or iPad no browser can, because they all use Safari's engine underneath.

Everything before connecting still works here: pick a board, see exactly which file would be written, and verify its hash.

Needs Chrome, Edge, or Opera on a desktop. Firefox and Safari cannot talk to the radio.
